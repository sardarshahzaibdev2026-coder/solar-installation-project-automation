# Solar Installation Project Tracking Automation

## Project Overview
This project automates solar installation customer registration and project tracking using n8n, Airtable, and Gmail.

## How It Works
1. Customer submits a solar installation registration form.
2. n8n collects customer information.
3. Project details are automatically saved in Airtable.
4. A unique Project ID and initial project status are assigned.
5. Customer receives an automatic confirmation email.

## Features
- Automated customer registration
- Project data management with Airtable
- Project status tracking
- Automatic customer confirmation emails
- Reduced manual data entry
- Organized solar project management

## Tools Used
- n8n
- Airtable
- Gmail

## Workflow
Form Submission → Data Processing → Airtable Record Creation → Customer Confirmation Email

## Use Case
Designed for solar installation companies to manage new customer requests, organize project records, and improve communication.
